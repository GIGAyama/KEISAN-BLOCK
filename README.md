# さんすうブロック 🟧🟦🟩

小学1年生向けの算数学習アプリ（PWA対応）です。日本の算数教育で使われる「**算数ブロック**」と「**さくらんぼ計算**」を画面上で操作に合わせて動かすことで、**繰り上がりのたし算**・**繰り下がりのひき算**の考え方を視覚的に理解し、確実に定着させます。

## 教科書の「けいさんの しかた」をそのまま画面に

ステップの発問・順番・言い回しは、教科書の**4つの手順**に対応させています。

| | 9＋4 | 13−9 |
| --- | --- | --- |
| ❶ | 9は あと 1で 10。 | 3から 9は ひけない。 |
| ❷ | 4を 1と 3に わける。 | 13を 10と 3に わける。 |
| ❸ | 9に 1を たすと 10。 | 10から 9を ひくと 1。 |
| ❹ | 10と 3で 13。 | 1と 3で 4。 |

正解すると、その問題の数で書き起こした「**けいさんの しかた**」の4行が表示され、声に出して確かめられます。読む時間を確保するため **5秒間は必ず表示** され、5秒たつと「つぎへ」ボタンが押せるようになります（それまでは押せません）。

### ✏️ 式への「しるし」（さくらんぼ計算の書き込み）

教科書で鉛筆で書き込む印を、そのまま式の上に再現します。

- **わ（○囲み）**：10をつくる数の組を囲み、横に「10」と書き添える（9と1 → 10）
- **ななめ線**：使い終わった数を消す（10から9をひいたあとの「10」）
- **のこりの数**：消した数の下に小さく書き込む（10−9の「1」）
- **むすび**：あわせる2つの数をカーブでつなぐ（1と3 → こたえ）
- 使っている数はオレンジに変わり、これからあわせる数はゆれて教えてくれる

## 学習モード

### 🍒 たしざん（繰り上がり）— 「10の まとまりを つくる さくせん」

例）8 + 7

1. 「8は あといくつで 10？」→ **2**（10のまとまりの空きがハイライトされ、タップして数えられる）
2. 「7を 2と いくつに わける？」→ **5**（さくらんぼが埋まり、ばらのブロックも 2 と 5 の2かたまりに分かれる）
3. 分けた **2個を自分でタップして**10のまとまりに入れる →「8に 2を たすと？」→ **10**（わくが緑に光り、式には「8と2」を囲む○と「10」の書き込み）
4. 「10と 5で いくつ？」→ **15**

### 🔟 ひきざん（繰り下がり）— 2つの「さくせん」を練習

減加法・減減法といった用語は使わず、**やることがそのまま名前になった作戦名**で示します。

| 作戦名 | すすめかた |
| --- | --- |
| **10から ひいて たす さくせん** | 10のまとまりから先にひいて、のこりとばらをたす（13−9 → 10−9=1 → 1+3=4） |
| **ばらから ひいて 10から ひく さくせん** | ばらを先に全部ひいてから、10のまとまりからひく（13−9 → 13−3=10 → 10−6=4） |

作戦は選択でき、「ミックス」ではランダムに両方が出題されます。

### 🖐 ブロックは「見せる」から「自分でうごかす」へ

答えを入力する前に、**児童自身がブロックをタップして操作するステップ**が入ります。手を動かした結果が目の前に残るので、式の意味が実感として残ります。

- **とる**：「10の まとまりから ブロックを 9こ タップして とろう！」→ 残りを数えて答える
- **いれる**：「わけた 2こを タップして 10の まとまりに いれよう！」→ 10がそろって緑に光る
- 操作中はキーパッドが休み、「あと ◯こ」で残数を表示。4秒さわらないと次の1個が大きく揺れて教えてくれる
- まとめて進めたいときは「じどうで うごかす」ボタン
- **かたまりごとの個数を常時表示**（10の まとまり ◯こ／ばら ◯こ／10の ぼう ◯ほん）
- ブロックや空きマスをタップすると **1・2・3… と数字がついて数えられる**（押し直しで数えなおし）

### ⚡ タイムアタック（あんざん）

10問のあんざん勝負。タイムとまちがい数で★評価、最高タイムを記録します。ステップの支えを外して暗算での自動化（流暢性）を鍛えます。

### 🚀 はってん（能力の高い児童向け）

**2けた±1けた**（25＋8、33−6 など）に同じ「10のまとまり」の考え方を適用します。

- たしざん：次の「なん10」をつくる（77は あと3で 80 → 7を 3と4に → 84）。10個そろったまとまりが**10のぼうに合体**するアニメーション
- ひきざん：「ばらから ひいて 10から ひく さくせん」（37−9 → 37−7=30 → 30−2=28）。**10のぼうがばらけて**まとまりに戻るアニメーション

十のくらいのブロックは「10のぼう」で表現し、位取りの理解にもつながります。

### ✏️ じぶんで しきを いれる（先生・おうちの方むけ）

教科書やプリントで**つまずいた式をその場で入力**して、ブロックで一緒に考えられるモードです。個別の質問対応にも、電子黒板での一斉指導にも使えます。

- **入力できる式**：2けた±2けた（99まで／ひき算は答えが0以上）。`23＋14`、`25＋18`、`42−17`、`3＋4`、`30−7` など
- **教科書の作戦を自動で選択**：`9＋4`・`13−9`・`25＋8`・`33−6` のように既習の作戦がそのまま使える式は、**さくらんぼ計算の4ステップ**で進みます。`13−9` のように2通りの作戦がある式は、どちらで考えるかを選べます
- **それ以外の式**は「10の まとまりで かんがえる さくせん」に分解します（十のくらい → 一のくらいの順）
  - `42−17` → ❶ 17を 10と 7に わける ❷ 42から 10を ひくと 32 ❸ 7を 2と 5に わける ❹ 32から 2を ひくと 30 ❺ 30から 5を ひくと 25
  - 10のぼうも**タップして動かせます**（たすときは自分の束へ、ひくときは取りのぞく）
- **せつめいモード**（切り替え式）：答えの入力を求めず、「**こたえを 見る**」→ みんなで確かめる →「**つぎへ**」で進みます。先生が問いかけながら黒板で進めるための流れです
- **記録に残りません**：レベル・XP・にがてカード・カレンダーは一切更新されないので、先生のデモで児童の記録が動くことはありません

このモードだけキーボード操作にも対応しています（数字・`+`・`-`・Backspace・Enter）。

## 学習ログ（共通スキーマ `study.v1`）

GIGA山 学習アプリ群で共通の**学習ログ共通スキーマ `study.v1`** に対応しています。学習データを端末の `localStorage` に共通形式で保存し、教師が複数アプリを横断して閲覧・活用できるようにするためのものです。

- **このアプリが出力するスキーマ版：`study.v1`**（`appId: keisan-block` / `appVersion: 1.1.0`）
- **保存のみ。外部送信は一切しません。** 送信は同一オリジンに置かれる別ページ（送信ページ／ランチャー）の担当です
- **児童を識別する情報は持ちません。** 氏名・出席番号・端末情報はレコードに含めません（識別子は送信ページが付与）

### レコードの粒度

| モード | `kind` | 1レコードの範囲 |
| --- | --- | --- |
| ガイドつき練習（たしざん／ひきざん／はってん） | `set` | **5問ごと**（★が5つそろった時点で保存） |
| タイムアタック | `session` | 10問1回ぶん |
| じぶんで しきを いれる | — | **記録しません**（教師が入力した式のため。仕様書 §4） |

`mode` と `unit.id` は `add` / `genka` / `gengen` / `mix` / `timed` / `dev-add` / `dev-sub` / `dev-mix`。ミックスの区別を残すため、`mix` の発展版として `dev-mix` を追加しています（互換変更）。

### 主指標は「初回正答」

主指標は `summary.firstTryCorrect`（1回目の解答で正解した問題数）です。児童向けの表示でも `firstTryCorrect / attempted` を正答率として使います。

- 3回まちがえて**答えを見せて進んだ問題**は `items[].ok = false`（自分で解けていない）とし、`hint = true` を立てます
- ヒント表示・「じどうで うごかす」も `hint = true` として残します
- 中断時、一度も答えを入力していない問題は `attempted` にも `items` にも数えません。`count - attempted` が未着手数です

### 設問層（`items`）

`q` は問題文ではなく**設問ID**で、§2.10 の生成規則にしたがい**式そのもの**を用います（`8+7` / `13-9` / `25+8` / `48-9`）。けいさんカード（`8+5`）・100マス計算（`8+9`）と同じ形になるため、アプリを横断して「どの式でつまずいたか」を追えます。

- 20文字以内・日本語を含まないため、ハッシュ化はしません
- このアプリの習熟度マップのキー（`A8+7` / `S13-9`）は**アプリ内部のもの**なので設問IDには使わず、`ext.factKeys` に併記します
- 出題はランダム生成なので、同じ式が複数回出題されえます。`q` は1レコード内で一意とは限りません（集計側は同一 `q` を別々の試行として扱ってください）
- `summary.attempted` は常に `items.length` と一致します（非マージ方式）

### 拡張層（`ext`）

```jsonc
{ "strategy": "genka", "guided": true, "maxStreak": 6,
  "factKeys": ["S13-9", "S12-8"], "wrongFactKeys": ["S13-9"],
  "strategyStats": { "genka": { "count": 3, "firstTryCorrect": 2 } } }
```

`genka`（10からひいてたす＝減加法）と `gengen`（ばらからひいて10からひく＝減減法）の区別は、他アプリにない指導価値の高いデータとして必ず記録します。ミックスでは `strategyStats` に作戦ごとの定着状況を分けて残します。

### 中断（`status: "aborted"`）

「途中でやめた」ことは、**難しすぎる・量が多すぎるという重要なサイン**なので記録します。

- 練習画面で「やめる」を選んだとき
- タブが非表示になり、**5分**戻らなかったとき（数分の離席を中断と誤記録しないための猶予。短くしないこと）
- **`pagehide` でページが破棄されるとき**（タブを閉じた・リロード・Chromebook のメモリ不足やスリープによるタブ破棄）。5分タイマーごと消えてしまうため、ここで必ず確定します。`beforeunload` はモバイルや bfcache 経路で発火しないことがあるため使いません

中断レコードの3原則（§5.4）:

| 原則 | 実装 |
| --- | --- |
| `endedAt` / `elapsedMs` は**タブを離れた時刻**で締める | 待機していた5分を学習時間に含めません |
| **1問も答えていない中断は保存しない** | 学習データを持たないレコードでログ枠（500件）を埋めません |
| **復帰したら新しいレコードを開始する** | 中断済みレコードに追記せず、`count` は区切りの残り分（5問設定で `count: 3` が生じえます） |

復帰は `visibilitychange` と `pageshow`（bfcache 復帰）で検知します。記録対象外のモード・記録中のレコードがある場合・結果表示のオーバーレイが開いている場合は開始しません。

### ⚠️ `study.records.v1` を消さないでください

```
study.records.v1 は複数アプリ共通の学習ログです。このアプリ専用のキーではないため、
リセット処理やクリーンアップの対象に含めないでください。
```

- 「きろくを けす」で消えるのは**このアプリ固有のデータのみ**（レベル・XP・にがてカード・カレンダー・バッジ＝`keisan-block-v2`）。未送信ログが消えるため学習ログは消しません
- `localStorage.clear()` は使いません
- Service Worker の `activate` で消すキャッシュは、自アプリのプレフィックス（`sansu-block-`）が付いたものだけに限ります（同一オリジンの他アプリのキャッシュを壊さないため）

### 🐾 あしあと（学習ログの読み返し）

きろく画面の「あしあと」タブで、保存した学習ログを**児童本人に返します**（読み出し専用・外部送信なし）。

- この1週間の 取り組んだ回数／といた問題数／いっぱつせいかい率／学習時間
- モードごとの初回正答率バー
- さいきんの取り組み一覧（日付＋時間帯・作戦・いっぱつせいかい・時間・中断表示）

時刻は**時間帯（ごぜん／ごご／ゆうがた）までに丸めて**表示します（学習時刻から家庭の状況を推測させないため）。

## 定着と学習習慣のしくみ

- **けいさんマップ**：計算カード1枚1枚の習熟度をヒートマップ表示（ばっちり／もうすこし／にがて／まだ）。3回連続正解で「ばっちり」
- **適応出題**：にがてなカードを35%の確率で優先出題し、弱点を自動でつぶす
- **きょうのミッション**：1日10問の目標を進捗リングで表示。達成でカレンダーに⭐スタンプ
- **がんばりカレンダー**：月表示で学習した日にスタンプ。連続学習日数🔥も表示
- **XP・レベル**：正解でXPがたまり「けいさんみならい」→「けいさんマスター」へ成長
- **バッジ**：はじめの一歩、50問突破、連続10問正解、1週間継続、パーフェクトなど10種類
- **段階的ヒント**：1回目「もういちど！」→ 2回目ヒント → 3回目答えを見せて一緒に進む（つまずいても止まらない）

## PWA（アプリとしてインストール）

- Chrome などでアクセスすると、ホーム画面の「📲 アプリを インストール」ボタンやブラウザメニューからインストールできます
- Service Worker によりオフラインでも動作します
- スマートフォン・タブレット・PCに対応。横向き・大画面では問題エリアとキーパッドの2カラム表示になり、学習領域を広く使えます

## 使い方（開発者向け）

ビルド不要の静的Webアプリです。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

※ Service Worker を使うため、`file://` ではなく localhost か HTTPS で開いてください（GitHub Pages でそのまま公開できます）。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール不使用）
- 効果音は WebAudio API で生成（音声ファイル不要）、バイブレーション対応
- 記録は localStorage に保存

```
index.html            画面構成（ホーム／モード選択／練習／記録）
manifest.webmanifest  PWAマニフェスト
sw.js                 Service Worker（オフラインキャッシュ）
icons/                アプリアイコン
css/style.css         スタイル（子ども向けUI・アニメーション・レスポンシブ）
js/audio.js           効果音（WebAudio）
js/blocks.js          算数ブロック・10のぼう・さくらんぼの描画とアニメーション
js/marks.js           式への書き込み（○囲み・ななめ線・のこりの数・むすび）
js/storage.js         記録・レベル・習熟度・ミッション・バッジ（localStorage）
js/studyLog.js        学習ログの保存（study.v1 共通モジュール・全アプリ同一）
js/studySession.js    学習ログのくみたて（セット計測・設問層・中断検知）
js/studyStats.js      学習ログの読み出し・集計（「あしあと」表示用・読み出し専用）
js/main.js            問題生成・適応出題・ステップ進行・各モードの制御
```

### 学習ログの保存先

| localStorage キー | 中身 | 「きろくを けす」の対象 |
| --- | --- | --- |
| `study.records.v1` | 学習ログ（**複数アプリ共通**。このアプリ専用ではない） | **含めない** |
| `keisan-block-v2` | レベル・XP・習熟度・カレンダー・バッジ | 対象 |
| `keisan-block-explain` | せつめいモードの切り替え状態 | 対象外（設定のため） |

`js/studyLog.js` は仕様書 §5.1.2 の参照実装そのもの（**ロジック版 1.1** / §5.1.3）で、**全アプリで同一の動作**でなければなりません。このアプリはビルドしない `<script>` 構成のため、ESM ではなくグローバル形態（`globalThis.StudyLog.saveStudyRecord`）で公開しています。ロジック本体を変更しないでください。参照実装が改訂されたときは、ファイル先頭のロジック版を上げて仕様書 §5.1.3 の表も更新します。

学習時間（`elapsedMs` / `activeMs`）は §2.8 の参照実装で全モードを計測しており、`timeBasis` は `"app"` です（ランチャーによる外側計測への移行は §7 で任意となりました）。
