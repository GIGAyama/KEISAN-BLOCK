# さんすうブロック 🟧🟦🟩

小学1年生向けの算数学習アプリ（PWA対応）です。日本の算数教育で使われる「**算数ブロック**」と「**さくらんぼ計算**」を画面上で操作に合わせて動かすことで、**繰り上がりのたし算**・**繰り下がりのひき算**の考え方を視覚的に理解し、確実に定着させます。

## 学習モード

### 🍒 たしざん（繰り上がり）— さくらんぼ計算で「10のまとまり」をつくる

例）8 + 7

1. 「8は あといくつで 10？」→ **2**（10のわくの空きがハイライト）
2. 「7を 2と いくつに わける？」→ **5**（さくらんぼが埋まり、ブロック2個がわくへ飛んで10のまとまりが完成）
3. 「10と 5で いくつ？」→ **15**

### 🔟 ひきざん（繰り下がり）— 減加法と減減法の両方を練習

**減加法**：10からひいて、のこりとたす（13−9 → 10−9=1 → 1+3=4）
**減減法**：ばらからじゅんばんにひく（13−9 → 13−3=10 → 10−6=4）

方法は選択でき、「ミックス」ではランダムに両方が出題されます。

### ⚡ タイムアタック（あんざん）

10問のあんざん勝負。タイムとまちがい数で★評価、最高タイムを記録します。ステップの支えを外して暗算での自動化（流暢性）を鍛えます。

### 🚀 はってん（能力の高い児童向け）

**2けた±1けた**（25＋8、33−6 など）に同じ「10のまとまり」の考え方を適用します。

- たしざん：次の「なん10」をつくる（77は あと3で 80 → 7を 3と4に → 84）。10個そろったわくが**10のぼうに合体**するアニメーション
- ひきざん：減減法（37−9 → 37−7=30 → 30−2=28）。**10のぼうがばらけて**わくに戻るアニメーション

十のくらいのブロックは「10のぼう」で表現し、位取りの理解にもつながります。

## 定着と学習習慣のしくみ

- **けいさんマップ**：計算カード1枚1枚の習熟度をヒートマップ表示（ばっちり／もうすこし／にがて／まだ）。3回連続正解で「ばっちり」
- **適応出題**：にがてなカードを35%の確率で優先出題し、弱点を自動でつぶす
- **きょうのミッション**：1日10問の目標を進捗リングで表示。達成でカレンダーに⭐スタンプ
- **がんばりカレンダー**：月表示で学習した日にスタンプ。連続学習日数🔥も表示
- **XP・レベル**：正解でXPがたまり「けいさんみならい」→「けいさんマスター」へ成長
- **バッジ**：はじめの一歩、50問突破、連続10問正解、1週間継続、パーフェクトなど10種類
- **段階的ヒント**：1回目「もういちど！」→ 2回目ヒント → 3回目答えを見せて一緒に進む（つまずいても止まらない）

## PWA（アプリとしてインストール）

- Chrome などでアクセスすると、ホーム画面の「📲 アプリを インストール」ボタンやブラウザメニューからインストールできます
- Service Worker によりオフラインでも動作します
- スマートフォン・タブレット・PCに対応。横向き・大画面では問題エリアとキーパッドの2カラム表示になり、学習領域を広く使えます

## 使い方（開発者向け）

ビルド不要の静的Webアプリです。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

※ Service Worker を使うため、`file://` ではなく localhost か HTTPS で開いてください（GitHub Pages でそのまま公開できます）。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール不使用）
- 効果音は WebAudio API で生成（音声ファイル不要）、バイブレーション対応
- 記録は localStorage に保存

```
index.html            画面構成（ホーム／モード選択／練習／記録）
manifest.webmanifest  PWAマニフェスト
sw.js                 Service Worker（オフラインキャッシュ）
icons/                アプリアイコン
css/style.css         スタイル（子ども向けUI・アニメーション・レスポンシブ）
js/audio.js           効果音（WebAudio）
js/blocks.js          算数ブロック・10のぼう・さくらんぼの描画とアニメーション
js/storage.js         記録・レベル・習熟度・ミッション・バッジ（localStorage）
js/main.js            問題生成・適応出題・ステップ進行・各モードの制御
```
