# さんすうブロック 🟧🟦🟩

小学1年生向けの算数学習アプリ（PWA対応）です。日本の算数教育で使われる「**算数ブロック**」と「**さくらんぼ計算**」を画面上で操作に合わせて動かすことで、**繰り上がりのたし算**・**繰り下がりのひき算**の考え方を視覚的に理解し、確実に定着させます。

- **公開先**：<https://keisan-block.giga-school.com/>
- **入れるもの無し**：ブラウザで開くだけ。アカウント登録・ログイン・氏名入力の画面はありません
- **通信しない**：記録は端末の `localStorage` だけに保存し、外部へ送信しません
- **オフラインで動く**：一度開けば Service Worker で圏外でも使えます

## このアプリでできること

ホームには6つのメニューがあります。学習の中身はこの6つがすべてです。

| メニュー | 出題する式 | 1回の分量 | 記録 |
| --- | --- | --- | --- |
| 🍒 **たしざん** | 繰り上がりのあるたし算 `6+5`〜`9+9`（**26通り**） | 5問で1セット | 残る |
| 🔟 **ひきざん** | 繰り下がりのあるひき算 `11-2`〜`18-9`（**36通り**）／作戦を3択（10からひく・ばらからひく・ミックス） | 5問で1セット | 残る |
| ⚡ **タイムアタック** | 上の26＋36通りからランダムに、たし算・ひき算を50%ずつ | 10問1回 | 残る |
| 🚀 **はってん** | 2けた±1けた。たし算 `22+…`〜`79+…`／ひき算 `21-…`〜`78-…`（いずれも繰り上がり・繰り下がり必須） | 5問で1セット | 残る |
| ✏️ **じぶんで しきを いれる** | 打ちこんだ式を1問だけ。2けた±2けた（後述の制限内） | 1問ずつ | **残らない** |
| 📈 **きろく** | せいせき／あしあと／マップ／カレンダー／バッジの5タブ | — | — |

そのほか、画面の右上に**音のオン・オフ**と**「大きく表示」（電子黒板向け・全画面）**のボタンがあります。どちらも次に開いたときも設定が残ります。

## 教科書の「けいさんの しかた」をそのまま画面に

ステップの発問・順番・言い回しは、教科書の**4つの手順**に対応させています。

| | 9＋4 | 13−9 |
| --- | --- | --- |
| ❶ | 9は あと 1で 10。 | 3から 9は ひけない。 |
| ❷ | 4を 1と 3に わける。 | 13を 10と 3に わける。 |
| ❸ | 9に 1を たすと 10。 | 10から 9を ひくと 1。 |
| ❹ | 10と 3で 13。 | 1と 3で 4。 |

正解すると、その問題の数で書き起こした「**けいさんの しかた**」の4行が表示され、声に出して確かめられます。読む時間を確保するため **5秒間は必ず表示** され、5秒たつと「つぎへ」ボタンが押せるようになります（それまでは押せません）。

### ✏️ 式への「しるし」（さくらんぼ計算の書き込み）

教科書で鉛筆で書き込む印を、そのまま式の上に再現します。

- **わ（○囲み）**：10をつくる数の組を囲み、横に「10」と書き添える（9と1 → 10）
- **ななめ線**：使い終わった数を消す（10から9をひいたあとの「10」）
- **のこりの数**：消した数の下に小さく書き込む（10−9の「1」）
- **むすび**：あわせる2つの数をカーブでつなぐ（1と3 → こたえ）
- 使っている数はオレンジに変わり、これからあわせる数はゆれて教えてくれる

## 1問がどう進むか（タイムアタック以外に共通）

1. 画面の上に**作戦名の帯**（例：「10の まとまりを つくる さくせん」）と**式**、その下に**ブロック**が出る
2. 問いかけ（例「8は あと いくつで 10かな？」）が出て、**キーパッドで答える**
3. ステップによっては、答える前に**ブロックを自分でタップして動かす作業**が入る（この間キーパッドは休む）
4. 正解すると次のステップへ。最後のステップまで進むと1問終了
5. 5問そろうと「5もん クリア！」の画面（★5つ・のべ問題数）

**まちがえたとき**（タイムアタックを除く）:

| 回数 | 起きること |
| --- | --- |
| 1回目 | 「おしい！もういちど！」 |
| 2回目 | **ヒント**が出る（例「10の まとまりの あいている ところを タップして かぞえてみよう！」） |
| 3回目 | **答えを見せて一緒に進む**。この問題は「自分で解けていない」として記録される |

**もらえるXP**：基本モードは初回正解 10／やりなおして正解 5、はってんは 15／8、タイムアタックは1問 8。

## 学習モード

### 🍒 たしざん（繰り上がり）— 「10の まとまりを つくる さくせん」

例）8 + 7

1. 「8は あといくつで 10？」→ **2**（10のまとまりの空きがハイライトされ、タップして数えられる）
2. 「7を 2と いくつに わける？」→ **5**（さくらんぼが埋まり、ばらのブロックも 2 と 5 の2かたまりに分かれる）
3. 分けた **2個を自分でタップして**10のまとまりに入れる →「8に 2を たすと？」→ **10**（わくが緑に光り、式には「8と2」を囲む○と「10」の書き込み）
4. 「10と 5で いくつ？」→ **15**

### 🔟 ひきざん（繰り下がり）— 2つの「さくせん」を練習

減加法・減減法といった用語は使わず、**やることがそのまま名前になった作戦名**で示します。

| 作戦名 | すすめかた |
| --- | --- |
| **10から ひいて たす さくせん** | 10のまとまりから先にひいて、のこりとばらをたす（13−9 → 10−9=1 → 1+3=4） |
| **ばらから ひいて 10から ひく さくせん** | ばらを先に全部ひいてから、10のまとまりからひく（13−9 → 13−3=10 → 10−6=4） |

作戦は選択でき、「ミックス」では1問ごとにランダムで両方が出題されます。

### 🖐 ブロックは「見せる」から「自分でうごかす」へ

答えを入力する前に、**児童自身がブロックをタップして操作するステップ**が入ります。手を動かした結果が目の前に残るので、式の意味が実感として残ります。

- **とる**：「10の まとまりから ブロックを 9こ タップして とろう！」→ 残りを数えて答える
- **いれる**：「わけた 2こを タップして 10の まとまりに いれよう！」→ 10がそろって緑に光る
- 操作中はキーパッドが休み、「あと ◯こ」で残数を表示。4秒さわらないと次の1個が大きく揺れて教えてくれる
- まとめて進めたいときは「じどうで うごかす」ボタン（押すとヒントを使ったこととして記録します）
- **かたまりごとの個数を常時表示**（10の まとまり ◯こ／ばら ◯こ／10の ぼう ◯ほん）
- ブロックや空きマスをタップすると **1・2・3… と数字がついて数えられる**（押し直しで数えなおし）

### ⚡ タイムアタック（あんざん）

10問のあんざん勝負。ステップの支えもヒントも出さず、暗算での自動化（流暢性）を鍛えます。

| ★ | 条件 |
| --- | --- |
| ★★★ | まちがい **0回** かつ **60秒以内** |
| ★★☆ | まちがい **2回以内** かつ **90秒以内** |
| ★☆☆ | それ以外 |

タイムと最高記録は「きろく」→「せいせき」に残ります。

### 🚀 はってん（能力の高い児童向け）

**2けた±1けた**（25＋8、33−6 など）に同じ「10のまとまり」の考え方を適用します。十の位は 20〜70 台で、必ず繰り上がり・繰り下がりが起きる式だけを出します。

- たしざん：次の「なん10」をつくる（77は あと3で 80 → 7を 3と4に → 84）。10個そろったまとまりが**10のぼうに合体**するアニメーション
- ひきざん：「ばらから ひいて 10から ひく さくせん」（37−9 → 37−7=30 → 30−2=28）。**10のぼうがばらけて**まとまりに戻るアニメーション

十のくらいのブロックは「10のぼう」で表現し、位取りの理解にもつながります。一の位どうしの計算はけいさんカードと同じなので、**はってんの正誤もけいさんマップに反映されます**（25＋8 なら `5+8` のマス）。

### ✏️ じぶんで しきを いれる（先生・おうちの方むけ）

教科書やプリントで**つまずいた式をその場で入力**して、ブロックで一緒に考えられるモードです。個別の質問対応にも、電子黒板での一斉指導にも使えます。

- **入力できる式**：2けた±2けた。前後の数はそれぞれ **99まで**、たし算は**こたえも99まで**、ひき算は**前の数 ≧ うしろの数**（こたえが0以上）。`23＋14`、`25＋18`、`42−17`、`3＋4`、`30−7` など
- 条件から外れた式は「はじめる」が押せず、理由をその場で伝えます（例「37から 52は ひけないよ。おおきい かずを まえに いれてね。」）
- **教科書の作戦を自動で選択**：`9＋4`・`13−9`・`25＋8`・`33−6` のように既習の作戦がそのまま使える式は、**さくらんぼ計算の同じステップ**で進みます。`13−9` のように2通りの作戦がある式は、どちらで考えるかを選べます
- **それ以外の式**は「10の まとまりで かんがえる さくせん」に分解します（十のくらい → 一のくらいの順）
  - `42−17` → ❶ 17を 10と 7に わける ❷ 42から 10を ひくと 32 ❸ 7を 2と 5に わける ❹ 32から 2を ひくと 30 ❺ 30から 5を ひくと 25
  - 10のぼうも**タップして動かせます**（たすときは自分の束へ、ひくときは取りのぞく）
- **せつめいモード**（切り替え式）：答えの入力を求めず、「**こたえを 見る**」→ みんなで確かめる →「**つぎへ**」で進みます。先生が問いかけながら黒板で進めるための流れです。切り替えた状態は次回も残ります
- **記録に残りません**：レベル・XP・にがてカード・カレンダー・バッジ・学習ログは一切更新されないので、先生のデモで児童の記録が動くことはありません
- 解き終わると「おなじ しきを もういちど／べつの しきを いれる／ホームへ」を選べます

### キーボード操作

PC・電子黒板・外付けキーボードのために、マウスやタップがなくても答えられます。

| 画面 | 使えるキー |

## 定着と学習習慣のしくみ

- **けいさんマップ**：計算カード1枚1枚の習熟度をヒートマップ表示。たしざん**26マス**・ひきざん**36マス**の計62マス。3回連続正解で「ばっちり」（緑）、1回以上連続正解で「もうすこし」（黄）、直前にまちがえたままなら「にがて」（赤）、未挑戦は「まだ」（灰）
- **適応出題**：一度といたことがあって、まだ「ばっちり」になっていないカードを**35%の確率で優先出題**し、弱点を自動でつぶす
- **きょうのミッション**：1日**10問**の目標を進捗リングで表示。達成でカレンダーに⭐スタンプ
- **がんばりカレンダー**：月表示で、練習した日に✓、ミッション達成日に⭐。連続学習日数🔥も表示
- **XP・レベル**：正解でXPがたまりレベルが上がる。必要XPは `60 + 30×(レベル−1)`。称号は Lv1「けいさん みならい」→ 3・5・8・12・16 →  Lv20「けいさん マスター」の7段階
- **れんぞくせいかい**：一度もまちがえずに正解した連続数を画面右上に表示し、モードごとの最高記録を残す

## 学習ログ（共通スキーマ `study.v1`）

GIGA山 学習アプリ群で共通の**学習ログ共通スキーマ `study.v1`** に対応しています。学習データを端末の `localStorage` に共通形式で保存し、教師が複数アプリを横断して閲覧・活用できるようにするためのものです。

- **このアプリが出力するスキーマ版：`study.v1`**（`appId: keisan-block` / `appVersion: 1.1.0`）
- **保存のみ。外部送信は一切しません。** 送信は同一オリジンに置かれる別ページ（送信ページ／ランチャー）の担当です
- **児童を識別する情報は持ちません。** 氏名・出席番号・端末情報はレコードに含めません（識別子は送信ページが付与）

### レコードの粒度

| モード | `kind` | 1レコードの範囲 |
| --- | --- | --- |
| ガイドつき練習（たしざん／ひきざん／はってん） | `set` | **5問ごと**（★が5つそろった時点で保存） |
| タイムアタック | `session` | 10問1回ぶん |
| じぶんで しきを いれる | — | **記録しません**（教師が入力した式のため。仕様書 §4） |

`mode` と `unit.id` は `add` / `genka` / `gengen` / `mix` / `timed` / `dev-add` / `dev-sub` / `dev-mix`。ミックスの区別を残すため、`mix` の発展版として `dev-mix` を追加しています（互換変更）。

### 主指標は「初回正答」

主指標は `summary.firstTryCorrect`（1回目の解答で正解した問題数）です。児童向けの表示でも `firstTryCorrect / attempted` を正答率として使います。

- 3回まちがえて**答えを見せて進んだ問題**は `items[].ok = false`（自分で解けていない）とし、`hint = true` を立てます
- ヒント表示・「じどうで うごかす」も `hint = true` として残します
- 中断時、一度も答えを入力していない問題は `attempted` にも `items` にも数えません。`count - attempted` が未着手数です

### 設問層（`items`）

`q` は問題文ではなく**設問ID**で、§2.10 の生成規則にしたがい**式そのもの**を用います（`8+7` / `13-9` / `25+8` / `48-9`）。けいさんカード（`8+5`）・100マス計算（`8+9`）と同じ形になるため、アプリを横断して「どの式でつまずいたか」を追えます。

- 20文字以内・日本語を含まないため、ハッシュ化はしません
- このアプリの習熟度マップのキー（`A8+7` / `S13-9`）は**アプリ内部のもの**なので設問IDには使わず、`ext.factKeys` に併記します
- 出題はランダム生成なので、同じ式が複数回出題されえます。`q` は1レコード内で一意とは限りません（集計側は同一 `q` を別々の試行として扱ってください）
- `summary.attempted` は常に `items.length` と一致します（非マージ方式）
- 1問あたりに残す誤答は8件まで、`ext.factKeys` / `ext.wrongFactKeys` は各50件までに切ります（`ext` は 8KB まで）

### 拡張層（`ext`）

```jsonc
{ "strategy": "genka", "guided": true, "maxStreak": 6,
  "factKeys": ["S13-9", "S12-8"], "wrongFactKeys": ["S13-9"],
  "strategyStats": { "genka": { "count": 3, "firstTryCorrect": 2 } } }
```

`genka`（10からひいてたす＝減加法）と `gengen`（ばらからひいて10からひく＝減減法）の区別は、他アプリにない指導価値の高いデータとして必ず記録します。ミックスでは `strategyStats` に作戦ごとの定着状況を分けて残します。タイムアタックは `stars` / `misses` / `bestMs` / `isBest` / `msPerProblem` を残します。

### 中断（`status: "aborted"`）

「途中でやめた」ことは、**難しすぎる・量が多すぎるという重要なサイン**なので記録します。

- 練習画面で「やめる」を選んだとき
- タブが非表示になり、**5分**戻らなかったとき（数分の離席を中断と誤記録しないための猶予。短くしないこと）
- **`pagehide` でページが破棄されるとき**（タブを閉じた・リロード・Chromebook のメモリ不足やスリープによるタブ破棄）。5分タイマーごと消えてしまうため、ここで必ず確定します。`beforeunload` はモバイルや bfcache 経路で発火しないことがあるため使いません

中断レコードの3原則（§5.4）:

| 原則 | 実装 |
| --- | --- |
| `endedAt` / `elapsedMs` は**タブを離れた時刻**で締める | 待機していた5分を学習時間に含めません |
| **1問も答えていない中断は保存しない** | 学習データを持たないレコードでログ枠（500件）を埋めません |
| **復帰したら新しいレコードを開始する** | 中断済みレコードに追記せず、`count` は区切りの残り分（5問設定で `count: 3` が生じえます） |

復帰は `visibilitychange` と `pageshow`（bfcache 復帰）で検知します。記録対象外のモード・記録中のレコードがある場合・結果表示のオーバーレイが開いている場合は開始しません。

### ⚠️ `study.records.v1` を消さないでください

```
study.records.v1 は複数アプリ共通の学習ログです。このアプリ専用のキーではないため、
リセット処理やクリーンアップの対象に含めないでください。
```

- 「きろくを けす」で消えるのは**このアプリ固有のデータのみ**（レベル・XP・にがてカード・カレンダー・バッジ＝`keisan-block-v2`）。未送信ログが消えるため学習ログは消しません
- `localStorage.clear()` は使いません
- Service Worker の `activate` で消すキャッシュは、自アプリのプレフィックス（`sansu-block-`）が付いたものだけに限ります（同一オリジンの他アプリのキャッシュを壊さないため）

### 🐾 あしあと（学習ログの読み返し）

きろく画面の「あしあと」タブで、保存した学習ログを**児童本人に返します**（読み出し専用・外部送信なし）。

- この1週間の 取り組んだ回数／といた問題数／いっぱつせいかい率／学習時間
- モードごとの初回正答率バー
- さいきんの取り組み一覧（日付＋時間帯・作戦・いっぱつせいかい・時間・中断表示）

時刻は**時間帯（ごぜん／ごご／ゆうがた）までに丸めて**表示します（学習時刻から家庭の状況を推測させないため）。

## PWA（アプリとしてインストール）

- Chrome などでアクセスすると、ホーム画面の「アプリを インストール」ボタンやブラウザメニューからインストールできます（ボタンはブラウザがインストール可能と判断したときだけ出ます。iOS/iPadOS の Safari では出ないため、共有ボタン →「ホーム画面に追加」を使います）
- Service Worker によりオフラインでも動作します
- スマートフォン・タブレット・PCに対応。横向き・大画面では問題エリアとキーパッドの2カラム表示になり、学習領域を広く使えます

### 更新のとどけかた（押されるまで切りかえない）

`install` の中で `skipWaiting()` を**呼びません**。新しい版が待機したら
画面下に「あたらしい ばんが あります／さいしんに する」を出し、
**児童が押したときだけ**切りかえます。練習中に勝手に入れかわると、
打ちかけの答えとならべたブロックが消えるためです。

`controllerchange` は**利用者が押したときだけ**受けます。そのまま受けると、
`clients.claim()` でページが管理下に入る初回訪問でも発火し、
**はじめて開いたときに必ず1回リロードされます**。

リリースのたびに `sw.js` の `APP_VERSION` を上げてください。
上げ忘れると、直したはずのものが端末に届きません。

### アイコンの作りなおし

`icons/` は `icon-512.png` から生成します。手で置きかえないでください。

```bash
python3 -m pip install pillow
python3 tools/make-icons.py
```

maskable は、円で切りぬかれても中身が欠けないよう
**下地を端まで伸ばし、中身をセーフゾーン（中央80%）に収めた別画像**です。
`icon-512.png` をそのまま `purpose: "maskable"` として使ってはいけません
（以前それをしていて、白いカードの四隅が欠けていました）。

### Content-Security-Policy

`index.html` の `<meta http-equiv>` で `'self'` に締めています。
**`'unsafe-inline'` を足さないでください。** 足すと入れた意味がほとんど無くなります。
そのために、次の2つを守ってください。

- 本体の JavaScript は `index.html` に直接書かず、外部ファイルに置く
- `onclick=` を使わず `addEventListener` でつなぐ
- `innerHTML` の中に `style="..."` を書かない
  （HTML に書いた style属性は止められます。要素の `.style` への代入は止められません）

`frame-ancestors` は `<meta>` では無視されるため書いていません。
独自ドメインや CDN を挟むときに HTTP ヘッダーで設定してください。

## 使い方（開発者向け）

ビルド不要・依存パッケージなしの静的Webアプリです。Node は検査を走らせるためだけに使います（v20 以上）。

```bash
python3 -m http.server 8000   # = npm run serve
# → http://localhost:8000
```

※ Service Worker を使うため、`file://` ではなく localhost か HTTPS で開いてください（GitHub Pages でそのまま公開できます）。

### 変更したら通すもの

CI（`.github/workflows/ci.yml`）は `pull_request` と `push`（main）の両方で、次の5つを順に走らせます。手元でも同じものを通してください。

```bash
npm run check                                   # 品質ゲート（GIGA Standard Part I）
npm test                                        # node --test tests/*.test.mjs
for f in js/*.js sw.js install-hook.js scripts/*.mjs scripts/lib/*.mjs; do node --check "$f"; done
node -e "JSON.parse(require('fs').readFileSync('manifest.webmanifest','utf8'))"
python3 tools/make-icons.py && git diff --exit-code -- icons/   # 手で置きかえていないか
```

品質ゲートの見送り項目とその理由は `quality.config.json` の `gigaV4.exceptions` に書きます。検査をゆるめるのではなく、理由を残してください。

**測った値は `AUDIT.md` にあります。** 変更したら測りなおして、
そこの数字も更新してください。**測っていないものは「未計測」と書きます。**

`main` への push は GitHub Pages へ自動デプロイされます（`.github/workflows/deploy-pages.yml`）。

## 対応端末とアクセシビリティ

| 端末 | 確かめたこと |
|---|---|
| 320×568（最小） | 横スクロールが出ないこと |
| 1366×768（Chromebook） | コントラスト・タップ領域を全画面で走査 |
| 1920×1080（電子黒板） | 提示モードで全画面を走査 |

- **コントラスト**：本文 4.5:1 以上、大きな文字 3:1 以上。面用の色と文字用の色を
  2段階に分けています（`--*-surface` / `--*-text`）。ひとつの値で両方を
  まかなうと、かならずどちらかが届きません
- **タップ領域**：44px 以上。ボタン自体は大きくせず、疑似要素で当たり判定だけ広げています
  （`min-height` で背を伸ばすと、詰めて組んだタブが折り返して別の破綻を生みます）
- **拡大を禁止していません**（`user-scalable=no` を書きません）
- **キーボードのみ**で全機能に到達できます。オーバーレイはフォーカスを閉じこめ、
  Esc で閉じます（背後の画面は `inert`）
- **`prefers-reduced-motion`** に対応。値は `.01ms` であって `0` ではありません。
  `0` にすると `animation-fill-mode: forwards` が壊れ、とんでいくブロックが
  `opacity: 0` のまま消えます
- **`forced-colors`**（ハイコントラストモード）に対応
- **提示モード**：`body.presentation` で文字150%・ボタン64px・式を大きく
- **印刷用スタイルは持ちません**。画面で操作して考えるためのアプリで、印刷して配る作りにしていないためです（`quality.config.json` に理由つきで見送りを明記）

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール・CDN 不使用、依存パッケージ0）
- 効果音は WebAudio API で生成（音声ファイル不要）、バイブレーション対応
- 記録は localStorage に保存

```
index.html            画面構成（ホーム／モード選択／練習／記録）
manifest.webmanifest  PWAマニフェスト
sw.js                 Service Worker（オフラインキャッシュ）
icons/                アプリアイコン（tools/make-icons.py で生成。手で置きかえない）
install-hook.js       beforeinstallprompt の捕捉（<head> の先頭で同期読み込み）
offline.html          圏外かつ本体が手元にないときの画面（外部資産・JS に頼らない）
tools/make-icons.py   アイコン生成（any / maskable / apple-touch-icon）
scripts/              品質ゲート（check-project.mjs ＋ lib/ の共通検査）
quality.config.json   品質ゲートの設定・見送り理由
tests/                node --test で走るテスト（学習ログ）
css/style.css         スタイル（子ども向けUI・アニメーション・レスポンシブ）
js/audio.js           効果音（WebAudio）
js/blocks.js          算数ブロック・10のぼう・さくらんぼの描画とアニメーション
js/marks.js           式への書き込み（○囲み・ななめ線・のこりの数・むすび）
js/storage.js         記録・レベル・習熟度・ミッション・バッジ（localStorage）
js/studyLog.js        学習ログの保存（study.v1 共通モジュール・全アプリ同一）
js/studySession.js    学習ログのくみたて（セット計測・設問層・中断検知）
js/studyStats.js      学習ログの読み出し・集計（「あしあと」表示用・読み出し専用）
js/main.js            問題生成・適応出題・ステップ進行・各モードの制御
MANUAL.md             先生・おうちの方むけの てびき
AUDIT.md              表示・PWA・アクセシビリティの実測値
ROLLOUT.md            他リポジトリに効く知見
docs/note/            画面つきの紹介記事
```

### 学習ログの保存先

| localStorage キー | 中身 | 「きろくを けす」の対象 |
| --- | --- | --- |
| `study.records.v1` | 学習ログ（**複数アプリ共通**。このアプリ専用ではない） | **含めない** |
| `keisan-block-v2` | レベル・XP・習熟度・カレンダー・バッジ・音の設定 | 対象 |
| `keisan-block-explain` | せつめいモードの切り替え状態 | 対象外（設定のため） |
| `keisan-block-present` | 提示モード（電子黒板）の切り替え状態 | 対象外（設定のため） |

`js/studyLog.js` は仕様書 §5.1.2 の参照実装そのもの（**ロジック版 1.1** / §5.1.3）で、**全アプリで同一の動作**でなければなりません。このアプリはビルドしない `<script>` 構成のため、ESM ではなくグローバル形態（`globalThis.StudyLog.saveStudyRecord`）で公開しています。ロジック本体を変更しないでください。参照実装が改訂されたときは、ファイル先頭のロジック版を上げて仕様書 §5.1.3 の表も更新します。

学習時間（`elapsedMs` / `activeMs`）は §2.8 の参照実装で全モードを計測しており、`timeBasis` は `"app"` です（ランチャーによる外側計測への移行は §7 で任意となりました）。
