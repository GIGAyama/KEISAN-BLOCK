# さんすうブロック 🟧🟦🟩

小学1年生向けの算数学習アプリです。日本の算数教育で使われる「**算数ブロック**」と「**さくらんぼ計算**」を画面上で操作に合わせて動かすことで、**繰り上がりのたし算**・**繰り下がりのひき算**の考え方を視覚的に理解できます。

## 学習内容

### たしざん（繰り上がり）— さくらんぼ計算で「10のまとまり」をつくる

例）8 + 7

1. 「8は あといくつで 10？」→ **2**（10のわくの空きがハイライトされる）
2. 「7を 2と いくつに わける？」→ **5**（さくらんぼに 2 と 5 が入り、ブロック2個がわくへ飛んで10のまとまりが完成）
3. 「10と 5で いくつ？」→ **15**

### ひきざん（繰り下がり）— 減加法と減減法の両方を練習できます

**減加法（げんかほう）**：10からひいて、のこりとたす

例）13 − 9

1. 「13は 10と いくつ？」→ **3**（さくらんぼで 13 を 10 と 3 に分ける）
2. 「10から 9を ひくと？」→ **1**（わくからブロック9個が飛んでいく）
3. 「1と 3で いくつ？」→ **4**

**減減法（げんげんほう）**：ばらからじゅんばんにひく

例）13 − 9

1. 「9を 3と いくつに わける？」→ **6**（さくらんぼで 9 を 3 と 6 に分ける）
2. 「13から 3を ひくと？」→ **10**（ばらのブロック3個が飛んでいく）
3. 「10から 6を ひくと？」→ **4**（わくからブロック6個が飛んでいく）

減加法・減減法は選択でき、「ミックス」ではランダムに両方が出題されます。

## 繰り返し練習のしくみ

- **5問1セット**：正解するたびに ⭐ がたまり、5問クリアでお祝い画面
- **連続正解ストリーク** 🔥 表示でやる気アップ
- **段階的ヒント**：1回目のまちがいは「もういちど！」、2回目はヒント表示、3回目は答えを見せて一緒に進む（つまずいても止まらない設計）
- **がんばりの記録**：モードごとの「といた数」「連続正解の最高記録」を端末に保存（localStorage）

## 使い方

ビルド不要の静的Webアプリです。

```bash
# そのままブラウザで開く
open index.html

# またはローカルサーバーで
python3 -m http.server 8000
# → http://localhost:8000
```

タブレット・スマートフォン・PC（キーボード入力対応）で動作します。

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール不使用）
- 効果音は WebAudio API で生成（音声ファイル不要）
- 記録は localStorage に保存

```
index.html      画面構成
css/style.css   スタイル（子ども向けUI・アニメーション）
js/audio.js     効果音（WebAudio）
js/blocks.js    算数ブロック・さくらんぼの描画とアニメーション
js/main.js      問題生成・ステップ進行・記録
```
