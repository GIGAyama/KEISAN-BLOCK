## 貼るまえに直すところ

見出しの1行目にある連載番号が `#◯` のままです。

```
# 教室で使えるかもしれないもの作り #◯ 「どうして そこで わけるの？」で止まらない。…
```

連載の何本目になるかは、こちらで確かめられませんでした。
note の記事一覧が外から読めず（403 が返ります）、検索で拾えたのは
「#5 コリドール」「#6 オンライン原稿用紙」までです。
番号を推測で埋めると連載が壊れるので、そのままにしてあります。
公開のまえに、ここだけ実際の番号に置きかえてください。

## note に貼る手順

1. 記事本文の1行目（`# ` で始まる行）を、note のタイトル欄に貼ります。`# ` は外してください
2. 残りの本文を、note の本文エディタに貼ります
3. 画像は自動では入りません。本文中の `![...](images/...)` の位置で、その画像を手でアップロードしてください
4. 画像のすぐ下にある一行が、その画像のキャプションです。note の画像キャプション欄へ移して、本文からは消してください
5. ハッシュタグ欄には `#GIGAスクール` `#小学校` `#算数` `#1年生` `#個別最適な学び` `#PWA` あたりを入れます

見出しは `##` で書いてあります。note は見出しから自動で目次を作るので、
そのまま貼れば目次ができます。太字・斜体・表・区切り記号は使っていません。

## 撮り直すときの手順

playwright はリポジトリに入れません（CI を重くしないため）。

```bash
npm i --no-save playwright
node <skill>/scripts/serve.mjs . 4180 /KEISAN-BLOCK/     # 別ターミナル
node <skill>/scripts/capture.mjs <シナリオ> --base http://127.0.0.1:4180/KEISAN-BLOCK/ --out out
```

このアプリはビルドしないので、配るのはリポジトリのルートそのままです。
ベースパス `/KEISAN-BLOCK/` を省かないでください。Service Worker と manifest が
`/KEISAN-BLOCK/` を前提にしているため、ルート直下で配ると本番と挙動が変わります。

撮影用のシナリオは `.tmp-shots/` に置いて作業し、納品時に消してあります。
リポジトリには残っていません。

撮るときにつまずいた点。

- 作業ステップ（タップしてブロックを動かす）が終わった直後は、
  ブロックの合体アニメーションが終わるまで問いかけの文が前のままです。
  そこで撮ると、ちがう画面が並びます。読み直して待つ処理が要ります
- 「けいさんの しかた」が出ているあいだは5秒たつまで「つぎへ」が押せません。
  押せるようになるまで待たないと、そこから先の画面がすべてずれます
- 画面が一度ずれると、そのあとの「ホームへ」や「はってん」が押せず、
  以降の撮影が全部だまってずれます。区切りごとにホームへ戻す処理を入れました
- 「じぶんで しきを いれる」の 42−17 は、いちばん最初が
  「10の ぼうを 1ほん タップして とろう！」という作業ステップです。
  はじめる直後に撮ると、せつめいモードの「こたえを 見る」は写りません
- タイムアタックの結果は、初回だとバッジ獲得のおしらせが画面の上にかぶります。
  2回目の結果を撮ると、かぶらずに済みます
- 問題はランダムに出ます。「ばらを6こ取る」のような見せたい形が出るまで、
  何問か回して待つ必要があります

## 文体について踏襲したこと

- 太字・斜体・表・区切り記号（`→` `／` `▲` `▶`）を使っていません
- Markdown は見出しだけです
- 箇条書きは手順のときだけで、それ以外は文章で書いています
- 専門用語を日常の言葉に置きかえています（ローカルストレージ、Service Worker、
  デプロイといった言葉は本文に出しません）
- 絵文字は見出しだけです
- 見出しは連載の基本形に、目玉の機能ぶんを2本足しています
  （🖐 ブロックを動かすのは、子どもたち自身です／💬 黒板の前で使う「せつめいモード」）
- 「導入のメリット」は「三つのいいことが期待できます。」から始める型にしています
- 結びは #9 と同じ一文にしています
- 教室での出来事は実体験として書いていません。「こうなればいいと思って作った」
  「〜だと思います」までにとどめています
- 効果を言い切っていません

本文の字数は約8,000字です（画像の記法を除いた文字数）。
